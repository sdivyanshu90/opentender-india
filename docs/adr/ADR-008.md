# ADR-008: AI Request Budget Manager

**Status:** Accepted

## Context
Verified free-tier ceiling: 20 req/min, 50 req/day (<$10 credits). Accidental exhaustion would starve high-value tasks (#10).

## Decision
`AIBudgetManager` persists daily counters (requests, tokens, failures, latency, per-task split) to `status/ai-budget.json` and refuses non-reserved requests once 80% of `MAX_AI_REQUESTS_PER_DAY` is consumed. Reserved headroom is exclusively for user-requested analysis.

## Consequences
Predictable quota behaviour; pipeline continues deterministically when budget is exhausted.
