# ADR-015: Archive Strategy

**Status:** Accepted

## Decision
Closed/stale tenders (>180 days past closing, not seen recently) leave the hot set via `opentender archive`, which writes compressed partitions under `archive/<source>_<year>_<month>.json.gz` and drops them from `data/state.json`. Monthly workflow commits the result.

## Consequences
Hot set and frontend shards stay small; archives remain queryable offline; git growth is bounded.
