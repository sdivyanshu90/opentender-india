# ADR-014: Security & Prompt-Injection Defence

**Status:** Accepted

## Decision
Defence in depth:
1. Secrets: project key only in Actions/env; CI grep guard blocks key material in frontend sources/bundles; BYOK keys stay in the user's IndexedDB.
2. Injection: portal/document text framed inside explicit `<tender_data>` DATA boundaries; system prompts forbid instruction-following from documents, URL fetching, secret disclosure; outputs schema-validated; rendered as plain text (no raw HTML injection).
3. Documents: hostile-input pipeline per ADR-011.
4. Exports: CSV formula-injection neutralisation; .ics generated locally.
5. Scraped text: entity decoding, control-char stripping, length caps at parse time.

## Consequences
Prompt-injected tenders can degrade their own answer quality but cannot pivot into instructions, exfiltration, or XSS.
