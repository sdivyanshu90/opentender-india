# ADR-006: Search Architecture - Client-Side MiniSearch

**Status:** Accepted

## Context
Zero budget rules out hosted search; #72 weights exact IDs highest and wants typo tolerance.

## Decision
Pipeline emits compressed slim documents (`search-docs.json.gz`); the browser builds a MiniSearch index at load (fast at <=10k records), boosted toward tender_number/ref > title > category > authority, prefix + fuzzy matching. Deterministic NLQ parsing converts natural language into structured filters before search (#14).

## Consequences
Zero search infrastructure cost; revisit client-side indexing beyond ~50k records (SQLite FTS path documented for self-hosted mode).
