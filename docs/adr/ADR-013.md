# ADR-013: Frontend Architecture

**Status:** Accepted

## Decision
React 18 + TypeScript + Vite + Tailwind, react-router-dom, MiniSearch, idb-keyval. Three-zone workspace (nav rail / dense table / collapsible Copilot) on desktop; sticky search + bottom nav + bottom-sheet filters on mobile; filter state encoded in URLs (#57). Deliberately minimal dependency list.

## Consequences
Small static bundle (~82 KB gz JS); every core feature works without AI and without login.
