# ADR-011: Hostile Document Processing Pipeline

**Status:** Accepted

## Threat model
Tender PDFs/XLSX are attacker-controlled input (§24, §82).

## Decision
pypdf for text; openpyxl read_only/data_only (formulas never evaluated). Magic-byte MIME validation rejects legacy OLE outright (macro carrier); 25 MB cap; zip-bomb guards (ratio/entries/depth) for OOXML; sha256 recorded; safe_filename neutralises traversal; extraction failures degrade the record, never the pipeline. LibreOffice/Tesseract deferred until justified.

## Consequences
No code-execution surface from documents; extraction quality trades against attack surface by design.
