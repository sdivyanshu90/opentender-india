# ADR-012: GitHub Automation Topology

**Status:** Accepted

## Decision
Six workflows: `fetch-tenders.yml` (daily 02:17 IST, concurrency-guarded, commits only meaningful diffs), `weekly-reconcile.yml` (Sunday full pass + historical enrichment), `source-health.yml` (6-hourly smoke tests), `archive.yml` (monthly compaction), `ci.yml` (ruff/pytest/tsc/build + secret-leakage guard), `deploy.yml` (Pages).

## Consequences
Failure isolation is structural: every source step tolerates individual failure with `::warning::` annotations instead of failing the workflow.
