# ADR-010: Three-Mode AI Privacy Model

**Status:** Accepted

## Decision
Modes enforced client-side (#34): **local** (nothing leaves device), **public** (only public tender/document data may reach providers), **personal** (profile context additionally permitted after explicit opt-in). Private notes are never uploaded in any mode. Current mode always visible in the Copilot header.

## Consequences
Compliance by construction: input assembly sits behind the mode gate, so profile data cannot leak into requests while local/public modes are active.
