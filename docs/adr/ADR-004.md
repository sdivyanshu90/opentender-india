# ADR-004: GePNIC Strategy - One Configurable Adapter

**Status:** Accepted

## Context
~40 NIC deployments share identical Tapestry page names, row grammar, tender-ID format and login-only CAPTCHA policy, but skew across versions and hosts (verified live; docs/source-research.md).

## Decision
One `GePNICAdapter` driven by per-deployment YAML (app_path, harvest strategy, page budgets, delays). Runtime CAPTCHA guard halts politely per deployment. MahaTenders ships as config marked POLICY_RESTRICTED (robots.txt `Disallow: /`) - disabled unless the operator sets `OPEN_TENDER_ALLOW_POLICY_RESTRICTED=1`.

## Consequences
No copy-pasted scraper files; genuinely divergent portals get their own adapter family instead of config contortions.
