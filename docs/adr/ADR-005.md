# ADR-005: Dataset Storage

**Status:** Accepted

## Context
One giant JSON file would make diffs unreviewable and frontend loads slow (§44).

## Decision
Hot storage = per-tender gzip JSON at `data/hot/<prefix>/<canonical_id>.json.gz` plus `data/state.json` (revision/hash/status index used for cross-run diffing). Frontend payloads = slimmed shards under `data/indexes/` with a manifest. Source documents are never committed - metadata, hashes and extracted text only.

## Consequences
Git history stays reviewable; corruption affects single records; exports regenerate deterministically.
