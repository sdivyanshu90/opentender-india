# ADR-001: Zero-Cost Architecture

**Status:** Accepted · **Date:** 2026-08-23

## Context
The platform must operate at a ₹0/month baseline while ingesting from dozens of portals and serving a public search product (spec §7).

## Decision
All mandatory infrastructure is GitHub-native: Actions for scheduled ingestion, Pages for static hosting, the git repository for dataset storage, and browser-local storage (IndexedDB) for user state. No paid service is required anywhere in the stack.

## Consequences
- Dataset size must be managed (sharded gzip + monthly archive compaction).
- AI capacity is bounded by free-tier limits, so budgeting/cache/priority queue are first-class components.
- Live interactive AI requires BYOK: a server-held key cannot be exposed to static clients.
