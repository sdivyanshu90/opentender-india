# ADR-007: OpenRouter Integration

**Status:** Accepted

## Context
Free-model availability churns constantly (18 :free models on verification day, several with expiry dates); hard-coding any model guarantees breakage (#9).

## Decision
`AIProvider` protocol with `OpenRouterProvider` default. Models come from env (`OPENROUTER_MODEL=openrouter/free` or comma-separated fallback chain sent via OpenRouter's `models[]`). Retry honours `Retry-After`; structured outputs via `response_format: json_schema`. Attribution headers set. Project key exists only in Actions secrets/env; browsers use BYOK stored locally.

## Consequences
Model outages degrade gracefully; capability discovery can later use GET /models without contract changes.
