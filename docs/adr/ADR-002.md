# ADR-002: Canonical Tender Schema

**Status:** Accepted

## Context
Ten+ heterogeneous portals must merge into one queryable model without losing provenance (spec §41).

## Decision
A versioned JSON Schema (`packages/schema/canonical_tender.schema.json`, draft 2020-12) is the source of truth. Pydantic models (`scrapers/core/models.py`) and TypeScript types mirror it; CI validates fixtures against the JSON Schema. AI-derived fields never live in canonical records - they ship as separate artifacts keyed by `canonical_id`.

## Consequences
`merge_preserving_history` never blanks fields that disappear upstream; content hashing excludes timestamps so only evidence changes invalidate caches.
