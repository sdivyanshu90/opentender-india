# ADR-003: Adapter Framework

**Status:** Accepted

## Context
Each portal fails differently; one broken source must never take down ingestion (§47, #76).

## Decision
Every source implements `TenderSourceAdapter` (fetch_incremental / fetch_detail / healthcheck) plus `fetch_outcome()` for run-level stats. The registry instantiates adapters from `scrapers/configs/sources.yaml`; each fetch runs in isolation and records success/failure/CAPTCHA/anomaly into the health tracker independently.

## Consequences
Adding a source = adapter class + YAML entry + HTML fixtures + tests + recon report. Nothing else changes.
