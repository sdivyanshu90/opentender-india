# ADR-009: RAG Without Paid Vector Infrastructure

**Status:** Accepted

## Decision
Deterministic page-preserving chunking (`chunk_extracted_text`: page boundaries -> heading detection -> paragraph budget) yields chunks with {doc, page} references stored per canonical_id. Retrieval is lexical selection over shipped chunks before inference; no embedding service required. Local/browser embeddings remain optional future extensions (#26).

## Consequences
Citations resolve to real pages/clauses; fabricated citations are structurally impossible because prompts receive only shipped chunks.
